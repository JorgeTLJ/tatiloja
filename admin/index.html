Entrar no painel

O painel grava as alterações direto no repositório do site, usando a sua conta do GitHub. Cole abaixo o token de acesso (só aparece uma vez). Ele fica salvo apenas neste navegador.

Como criar o token (2 minutos)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: Painel Tati Loja. Validade: 1 ano.
  3. Em Repository access, escolha Only select repositories e marque tatiloja.
  4. Em Permissions → Repository permissions, coloque Contents: Read and write.
  5. Clique em Generate token e copie o código que começa com github_pat_.
